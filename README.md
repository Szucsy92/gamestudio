# GameStudio

Szeretnék egy fa renderképet létrehozni.
A tervem, csak a faágak, törzs és gyökerek lennének. Egy mesh-ben elkészítve.
Csatolom a referencia képet.
A célom egy kotlin nyelven értelmezhető vizuálisan megjeleníthető verzió.
A csatolt fájl egy példa rá.
Viszont a finomítást vizuálisan szeretném követni. Tehát egy 3d render kell hozzá, hogy éppen hogyan néz ki amit készítünk.
Ezek kellenek mind.
Viszont a referencia képre kell átalakítani!
Minden részletét lehessen finomhangolni. Gyökerek hosszát, a csúcsosságát, a fa ágainak számát és elhelyezkedését. A magasságot.
Annyit még hozzá tennék, hogy az elkészült finomhangolt mesh-t és az összes fájlt, zip-ben letölthessem.
Mehet a build.
